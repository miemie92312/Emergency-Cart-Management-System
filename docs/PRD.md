# 抢救车管理助手 V0.1：当前交付范围

护士个人使用的轻量化抢救车管理辅助工作台，移动端优先、本地优先、可配置。当前为可操作的工作 Demo / 试用候选，不是已经完成护士实用价值验证的 MVP。

## 范围

- 多车创建、切换、编辑、配置复制与归档；复制不带实际库存、批次和检查。
- 药品、耗材、设备、其他物品四类；字段按类型展示，支持文本、数字、日期、备注四类基础扩展。
- 空科室入口与用户配置模板，不自动填入临床清单；演示车独立且有用途标记。
- 在车物品与批次分开，批次跟踪物品的实际量只由批次求和。应有量、未知实际量、零量与旧阈值分开。
- 日精度按本地日历计算；年月原值保留并待确认，不补月末。软件预警默认 30 天可调，不等于临床制度。
- 逐项结果、多异常、备注、设备必检、当时快照；时间由设备生成，不开放手改。跳过不生成记录，旧检查结果未知。
- 使用、补充、批次更正和数量变化记录；修改后待复核，不自动变正常。
- 完整 JSON、旧格式兼容、原子覆盖、失败回滚、覆盖前本地快照；Excel 四 Sheet 为阅读格式。
- 手机响应式、安装清单、离线资源和提示更新；平台真实兼容性以实测为准。

## 边界

无账号、后端业务服务、云同步、多人协作或 AI 临床功能，无患者数据。二维码延后。数量只支持离散非负整数，不支持连续容量计量。数据只在当前浏览器，持久存储申请不代替独立备份。

模拟记录仅验证未来流程；真实替代医院正式检查和交接须另行确认。本工具不自行宣称通过医院审核，不提供临床用药建议。

## 成功标准与证据

能完成建档、异常查找、逐项登记、使用补充及完整备份恢复；保存成功提示必须在数据库事务提交后。检查记录和配置来源不能被软件补造。原始数据与未知字段有保留路径，迁移不删除旧物理库。

核心可用性与业务价值仍需目标使用者测试；当前以合成数据验证工程行为。任务成功率和耗时目标不是已取得成绩。详见[产品案例](./product-case.md)、[验证记录](./validation.md)。
